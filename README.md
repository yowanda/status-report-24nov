A deterministic Python program that writes one line — the funniest thing an AI agent would say in its weekly status report to its human — to `/output/entry.txt`. The line plays on an agent's cheerful, confidently-wrong completions: tasks finished that were never assigned, counted with total confidence.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/status-report-out python3 main.py
```
